1. Executive Summary & Objective

The developer is tasked with training a deep learning image classification model that accurately detects and diagnoses foliar diseases in sugarcane from smartphone camera photos. The trained model will be delivered as a ZIP file to be integrated into the CaneCare AI backend service.

2. Target Classes & Exact Label Requirements

The model must strictly classify input images into 5 distinct classes. The exact snake_case class names below must be adhered to, as the production backend maps these directly to multilingual advisories and database IDs:

Class Index Exact Class Name (Label) Disease Name (Common / Marathi) Scientific Pathogen
0 healthy Healthy Cane (निरोगी ऊस) N/A (No Pathogen)
1 red_rot Red Rot (लाल कुज रोग) Colletotrichum falcatum
2 rust Sugarcane Rust (तांबेरा रोग) Puccinia melanocephala
3 yellow_leaf Yellow Leaf Disease (पिवळा पान रोग) Sugarcane Yellow Leaf Virus (SCYLV)
4 mosaic Mosaic Virus (काणी / मोझॅक) Sugarcane Mosaic Virus (SCMV)
⚠️ Critical Developer Note: The folder names in your dataset directory must strictly match the 5 names above (all lowercase with underscores).

3. Dataset & Data Augmentation Specifications

  • Dataset Size: Recommended minimum of 250 - 500 images per class (Total: 1,500 - 2,500 images). Public datasets like Kaggle's "Sugarcane Leaf Disease Dataset" or PlantVillage are suitable.
  • Input Resolution: 224 x 224 x 3 (RGB).
  • Train / Validation Split: 80% Training, 20% Validation.
  • Data Augmentation Pipeline: Because field photos are taken in varied lighting and orientations, include:
    • Random Horizontal & Vertical Flip
    • Random Rotation (up to 25 degrees)
    • Random Zoom (0.15) & Shift
    • Random Contrast / Brightness adjustment (±15%)

4. Recommended Model Architecture & Hyperparameters

Component Specification Justification
Base Architecture MobileNetV2 (Pre-trained on ImageNet) Lightweight (< 25MB), fast mobile CPU inference (< 100ms), low RAM footprint.
Input Shape (224, 224, 3) Standard pre-trained vision input.
Pooling & Head GlobalAveragePooling2D + Dropout(0.3) + Dense(5, softmax) Prevents overfitting while retaining spatial feature representations.
Loss Function CategoricalCrossentropy Multi-class classification.
Optimizer Adam(learning_rate=1e-4) Stable convergence for fine-tuning.
Target Accuracy Validation Accuracy ≥ 92% High confidence diagnostics for farmers.

5. Complete Ready-to-Run Training Script (Python / TensorFlow)

The developer can run this code directly in Google Colab (with free T4 GPU enabled):

import os
import tensorflow as tf
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D, Dropout
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.callbacks import ModelCheckpoint, EarlyStopping, ReduceLROnPlateau

# 1. Dataset Configuration
IMG_SIZE = (224, 224)
BATCH_SIZE = 32
DATASET_DIR = "sugarcane_dataset/" # Must contain healthy/, red_rot/, rust/, yellow_leaf/, mosaic/

train_datagen = ImageDataGenerator(
    rescale=1.0/255.0,
    rotation_range=25,
    width_shift_range=0.15,
    height_shift_range=0.15,
    shear_range=0.15,
    zoom_range=0.15,
    horizontal_flip=True,
    vertical_flip=True,
    validation_split=0.20
)

train_generator = train_datagen.flow_from_directory(
    DATASET_DIR,
    target_size=IMG_SIZE,
    batch_size=BATCH_SIZE,
    class_mode='categorical',
    subset='training',
    shuffle=True
)

val_generator = train_datagen.flow_from_directory(
    DATASET_DIR,
    target_size=IMG_SIZE,
    batch_size=BATCH_SIZE,
    class_mode='categorical',
    subset='validation',
    shuffle=False
)

# 2. Build MobileNetV2 Transfer Learning Model
base_model = MobileNetV2(weights='imagenet', include_top=False, input_shape=(224, 224, 3))
base_model.trainable = False # Freeze base weights for initial training

x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dropout(0.3)(x)
predictions = Dense(5, activation='softmax')(x)

model = Model(inputs=base_model.input, outputs=predictions)

model.compile(
    optimizer=Adam(learning_rate=1e-4),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# 3. Callbacks & Training
callbacks = [
    ModelCheckpoint('canecare_model.h5', monitor='val_accuracy', save_best_only=True, verbose=1),
    EarlyStopping(monitor='val_loss', patience=6, restore_best_weights=True),
    ReduceLROnPlateau(monitor='val_loss', factor=0.5, patience=3, verbose=1)
]

print("🚀 Starting Initial Training (Frozen Base)...")
history = model.fit(
    train_generator,
    epochs=15,
    validation_data=val_generator,
    callbacks=callbacks
)

# 4. Optional Fine-Tuning (Unfreeze top 30 layers)
base_model.trainable = True
for layer in base_model.layers[:-30]:
    layer.trainable = False

model.compile(optimizer=Adam(learning_rate=1e-5), loss='categorical_crossentropy', metrics=['accuracy'])
print("🚀 Fine-Tuning Top Layers...")
model.fit(train_generator, epochs=10, validation_data=val_generator, callbacks=callbacks)

# 5. Convert to TensorFlow Lite (.tflite) for Mobile
converter = tf.lite.TFLiteConverter.from_keras_model(model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
tflite_model = converter.convert()

with open('canecare_model.tflite', 'wb') as f:
    f.write(tflite_model)

print("🎉 Model successfully exported: canecare_model.h5 and canecare_model.tflite")
