# CaneCare AI Backend

The CaneCare AI backend project is located in [`canecare-backend/`](./canecare-backend).

### Quick Start:
```bash
cd canecare-backend
.\venv\Scripts\activate
uvicorn app.main:app --reload
```
Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) in your browser.
For complete instructions, please read [canecare-backend/README.md](./canecare-backend/README.md).
